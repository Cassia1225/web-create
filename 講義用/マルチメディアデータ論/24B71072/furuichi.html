古市研究室

古市研究室では、学部三年生次にチームによるシリアスゲームの開発法とその評価方法など、 研究の進め方を学びます。四年生および大学院では、社会課題をテーマに設定し、 その解決に向けた実践的な研究を行います。さらに、研究成果を社会に応用することを目指し、 論理的思考力や問題解決能力を身につけることができます。また、学生同士で意見交換を行いながら 研究を進めることで、プレゼンテーション能力やコミュニケーション能力も身に付けることができます。

ゼミナールで学ぶ内容

ゼミナールでは、シリアスゲーム開発を中心に企画から設計、実装、評価までの一連の流れを学びます。 個人での開発をゼミ生同士で評価し、協調性や実践力も養われます。

研究室で学んでいるプログラムの一例

#include <stdio.h>

int main(void)
{
    int score;

    printf("点数を入力してください：");
    scanf("%d", &score);

    if(score >= 60){
        printf("合格です。\n");
    }else{
        printf("不合格です。\n");
    }

    return 0;
}

このプログラムは、入力された点数が60点以上なら「合格」、60点未満なら「不合格」と表示する C言語のサンプルです。変数、条件分岐（if文）、標準入出力（scanf・printf）の基本的な使い方を 学ぶことができます。
