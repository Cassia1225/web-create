数理情報工学科 岡研究室

研究室の概要

岡研究室では、ゲームエンジンUnityやCG制作に使用するblenderを用いてゲーム制作や映像制作、VRやAR技術の研究を行っています。
他の研究室と異なり、講義を行わず各自で制作を行いながら学んでいく、アウトプット学習がメインとなります。
また、桜泉祭などでは制作したゲームの体験会を行っています。3年次にはチームで作品を制作し、4年次では、作成した作品や個人製作の作品を用いて研究を行います。

ゼミナールで学ぶ内容

チームを組んでゲーム制作に取り組みます。ゲーム制作や映像制作を行いながらアプリケーションの操作やゲームプログラミングに取り組みます。

以下のプログラムは、ゲーム制作で使用するC#のプログラム例です。

using UnityEngine;
using UnityEngine.UI; // UIを扱うために必要

public class ButtonController : MonoBehaviour
{
    // インスペクターでUnityのButtonコンポーネントを紐付けます
    public Button myButton;

    void Start()
    {
        // ボタンがクリックされたときに実行するメソッドを登録
        myButton.onClick.AddListener(OnButtonClick);
    }

    void OnButtonClick()
    {
        Debug.Log("ボタンがクリックされました！");
    }
}
